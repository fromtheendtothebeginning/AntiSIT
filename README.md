# AntiSIT

校园服务 App —— 课程表 / 校园码 / 成绩 / 第二课堂 / 电费，一站式校园助手。

Flutter 编写的 Android / Windows 客户端，数据来自 [anticraft.top](https://anticraft.top) 开放接口（服务器代连校园内网并结构化数据，App 侧不接触校园密码）。

## 功能

- **课程表**
  - 多学期管理，周视图 / 日视图切换，滑动翻周、回到今天，过点课程自动置灰
  - 教务导入（逐周循环拉取全学期课表）、考试安排导入（转为日程事件）
  - 手动课程与日程事件（支持单次日期 / 每周重复），重叠课程可点选编辑、删除（支持"仅本周"自动拆分周次）
  - 调休设置（放假 / 按周 X 上课），渲染时生效，与网站规则互通
  - 云端同步：与网站共用同一份云端课表数据（`updatedAt` 最后写入胜），App 上的修改网站可见，反之亦然
  - 未登录也可使用：手动编辑、调休等本地功能不依赖账号
- **校园码**：动态付款码（55 秒自动刷新）+ 校园卡余额，亮码期间屏幕常亮
- **成绩**：全部学期 / 按学期查询（服务端过滤），平均绩点、学分绩点一览
- **考试安排**：期中 / 期末时间、地点、座位
- **第二课堂**：达标分数（细分达标着色）、活动看板（报名状态 / 关键词搜索 / 排序）
- **宿舍电费**：余额查询、充值（防重复扣款保护）、历史余额折线图（7 / 30 / 90 天）
- **演示模式**：内置本地假数据，无需账号即可体验全部界面

## 技术栈

- Flutter（Dart 3），Material 3
- 本地持久化：`shared_preferences`（课表 store / 登录态 / 设置）
- 网络：`http`，JWT 鉴权，401 单飞自动续期 / 重登，隧道类请求串行排队
- 课程表数据模型与网站 store 完全一致（字段名对齐，可双向同步）

## 构建

```bash
flutter pub get
flutter run                  # 连接设备/模拟器直接运行
flutter build apk --debug    # 或 --release
```

要求 Flutter 3.x 及以上。国内网络可配置 pub 镜像：

```bash
export PUB_HOSTED_URL=https://mirrors.cloud.tencent.com/dart-pub
```

## 隐私说明

- 仓库内**不含**任何真实个人信息、账号凭据、接口凭据或抓取数据
- App 不存储校园密码：校园凭据（学号 / 统一身份认证密码 / 支付密码 / 寝室）在 anticraft.top 网站「我的 → 校园服务」配置一次，由服务器加密保管
- App 本地仅保存：登录 token、课表数据、界面设置；可在「我的」页退出登录一键清除会话
- 演示模式使用本地假数据，不会发起任何请求
