# 二课达标线配置

达标线分三层，优先级从高到低：

1. **本机自定义**：二课分数页右上角「达标线设置」或「我的 → 设置 → 第二课堂达标线」，按入学年级保存，只影响本机。
2. **远端配置**：`https://anticraft.top/apk/score-targets.json`，App 缓存 24 小时，可按年级覆盖。
3. **内置默认规则**：现行达标线（8 / 3 / 3 / 1 / 1 等），不绑定某一届；远端或本机都没配置时用它。

源码里的模板是 [`tool/score-targets.json`](../tool/score-targets.json)。远端拉不到时用内置默认规则，本机自定义仍然优先。

## 本机调整

- 入口：分数页右上角「达标线设置」，或「我的 → 设置 → 第二课堂达标线」。
- 可改实践学分总目标、一级板块目标、二级条目目标；**留空表示该项不比较**。
- 修改只保存在本机，按当前年级生效；「恢复默认」会清掉本机自定义。
- 年级来源：教务返回的 `student.nj` 优先；直连模式可在「连接设置 → 直连模式 → 年级（入学年）」填写兜底。

## 结构

```json
{
  "default": {
    "total": 8,
    "groups": [
      { "keywords": ["德育"], "target": 3.0 }
    ],
    "subs": [
      { "keywords": ["讲座", "报告"], "target": 1.8 }
    ]
  },
  "cohorts": {
    "2027": { "total": 10, "label": "2027级" }
  }
}
```

- `default`：找不到该届覆盖时的兜底策略；不写或写 `null` 表示不比较。
- `cohorts`：按入学年（`nj`，4 位，如 `2027`）覆盖。某届写 `{}` 表示该届**明确不做达标比较**。
- `label`：可选，仅用于配置可读性；App 不在界面上把它当成通用规则。
- `groups[].keywords`：板块名包含任一关键词即命中。
- `groups[].target`：该板块目标；省略表示不比较。
- `groups[].noExpand`：`true` 时该板块不展开明细（美育 / 健康教育）。
- `subs[].keywords` / `subs[].target`：二级条目目标；`target` 省略表示只显示实际值。

## 年级从哪来

`/score` 返回的 `student.nj`（入学年）就是 `cohorts` 的键。没有该键时退回 `default`；两者都没有时，分数页只显示实际分数，并提示「本年级达标线尚未配置」。

## 更新规则

1. 改 `tool/score-targets.json`（或直接在服务器上改同一份 JSON）。
2. 上传到服务器：

   ```bash
   scp tool/score-targets.json root@47.100.125.150:/var/www/anticraft/dist/apk/score-targets.json
   ```

3. 验证：

   ```bash
   curl -s https://anticraft.top/apk/score-targets.json
   ```

App 最长 24 小时后自动换新；急用可清 App 数据或等下一次冷启动（缓存过期后）。

## 约定

- 内置默认规则和远端 `default` 都是「兜底」，不绑定某一届。学校按年级发新文件时，优先在 `cohorts` 里加该届覆盖，或让用户在三级页面本机调整；不要改默认值去冒充所有年级。
- 学校没有公布某届规则时，不要猜；让该届走默认，或写 `{}` 明确不比较。
- 本机自定义优先于远端和默认，只对保存时的年级生效；用户换年级后需要重新调整。
